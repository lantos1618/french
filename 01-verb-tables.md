# Top 15 verbs — combined tables

One table per verb. Persons down the side; **Past** (passé composé) · **Present** · **Future**
across the top. Read any row left-to-right as "I was → I am → I will be".

- **Past** = an auxiliary (*avoir* for most, *être* for a few) + the past participle.
- **Future** = the stem shown + endings **-ai / -as / -a / -ons / -ez / -ont**.
- ⚠️ marks **être-verbs**, whose participle agrees with the subject: allé(e)(s), venu(e)(s).

---

|---|---|---|---|

| il/elle | a été | est | sera |
| nous | avons été | sommes | serons |
| vous | avez été | êtes | serez |
| ils/elles | ont été | sont | seront |
